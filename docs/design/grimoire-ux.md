# 轮盘 UX 改造

默认入口为玩家魔典。按实际座次点击空位，搜索或按阵营筛选角色，选择后立即保存并关闭抽屉。再次点击可以更换、清除角色或记录死亡；记录面板支持撤销。所有录入默认私密，角色声称不自动变成真实身份假设。高级推理继续使用原标准工作区，八人示例保留在高级入口。

## 魔典推理闭环（2026-09-27）

玩家抽屉新增“记录信息”和“查询该玩家角色”。八类信息报告通过字段选择录入，默认私密；保存报告后进入魔典条件推理，分别采纳准确转述与能力有效。底部“推理”直接打开魔典内面板，高级工作区保留独立入口。

记录面板新增提名、投票、处决、死亡、猎手、胜负与阶段完整性表单。零票使用空选举手玩家表达；标记阶段完整前必须显式勾选确认。白天同时封闭行动与死亡，夜晚封闭死亡，重复确认不追加重复封闭事件。原始记录支持撤销，已撤销报告的采纳前提不会被静默应用。

查询绑定工作区快照，更改命题或前提会隐藏旧结果；异步旧结果也不会覆盖新版本。显示当前分支与修订、中文来源、支持见证、反例、未知原因与不完整日志提示。面板切换将键盘焦点移到标题；桌面与手机均可在抽屉中滚动完成操作。

本轮未扩充规则语义，也不声称最小冲突解释或完整 V1 已完成。

## 冲突定位与分支纠错（2026-09-27）

冲突结果中增加定位面板：标准/快速预算、取消、证据状态、相关采纳前提、原记录回看、单项删除后的有效见证，以及固定背景记录。明确区分已验证最小、已确认冲突但验证未完成、固定事实冲突和无法重新确认，未知结果不作为最小性证明。

试取消前提在当前修订上复制分支，保留原分支及事件历史，自动对新分支重新查询。对照面板展示相同命题下取消前后的结果，允许返回原分支；新分支仍有冲突或查询未知时明确说明。对照绑定对局、视角、查询、修订和原分支前提，切换到试验分支时将键盘焦点移到对照区域。

解释只最小化采纳前提，未最小化行动事实，也不宣称最少条数或唯一冲突原因。分支持久化，查询证据需刷新后重新生成。


## 声称分析与多人组合（2026-09-30）

魔典底部新增“一键分析”。在当前私密视角与分支修订下，自动临时检验开局身份真实、报告准确和能力有效，不需要先手动采纳前提。先确认固定事件与手动前提自身可以兼容，再定位玩家条件冲突，避免将固定背景矛盾归咎于玩家。所有分析均不修改已保存的前提、分支和事件。

组合搜索利用已确认冲突生成候选，复用当前快照中的检查结果，寻找需要同时放宽一人或多人的组合。每个组合必须具有兼容见证；逐人恢复该组合的条件均确认冲突后才标记“已验证不可再缩小”。界面显示具体角色对照、被放宽的报告来源、见证中的酒鬼所见身份和投毒行动，具体隐藏真相仍只标记为一种解释。

默认 30 秒、最多 6 组组合，区分搜索完成、展示上限、时间或检查预算、未知与最小性未完成。实时显示已有证据，取消保留已验证结果；关闭面板、工作区变化和重试均终止旧 Worker，过期进度不会重新显示。逐人试验放入展开区域，优先展示可以解释全部输入的组合。分析不提供撒谎概率，也不将组合合并成确定嫌疑名单。

天数选择统一为第 1–10 天。新对局会对仅有假设的工作区也提示替换确认；N2 等报告在随后同日白天封闭后仍可查询。此轮改善分析与交互，不扩充 22 角色规则语义。

本轮验收：146 项单元测试、生产构建、30 项本地生产预览 Chromium 浏览器回归通过；多人组合专项覆盖 1440×1000 与 390×844、来源、角色见证、单人回退、上限、取消及离线恢复。使用项目现有 Playwright，当前无可用 Browser 插件。
